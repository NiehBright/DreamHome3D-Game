### Issue: "Cannot resolve symbol 'GetPlacementRotation'"
**Solution**: This is IDE caching. Just save the file, IDE will refresh.
**Status**: Not actually an error (verified with get_errors)

### Issue: Shop doesn't appear
**Solution**: Check SETUP_SHOP_VISUAL.md section "Troubleshoot"

### Issue: Items don't show in shop
**Solution**: Verify FurnitureCatalog.asset has 5 items (not 2)

### Issue: Click doesn't work
**Solution**: Check Button component on prefab is set to Interactive

### Issue: Delete button doesn't work
**Solution**: Must tap on furniture first to select in delete mode
